## 🚀 Sobre o projeto

Este projeto consiste em um site portfólio responsivo desenvolvido em HTML e CSS, com o objetivo de apresentar meu perfil profissional, habilidades e formação na área de tecnologia.

O site foi estruturado com foco em **design moderno, experiência do usuário e organização de conteúdo**, simulando um portfólio profissional real.

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3 (com design responsivo e animações)
* Git e GitHub (versionamento de código)
* GitHub Pages (deploy e hospedagem)

---

## ✨ Funcionalidades

* Layout moderno com design dark mode
* Navegação por seções (Sobre, Habilidades, Formação e Contato)
* Interface responsiva para diferentes dispositivos
* Animações e efeitos visuais (hover, transições e background dinâmico)
* Seção de contato com links externos
